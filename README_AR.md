# MulkCare — عناية ببيتك في الغردقة

تطبيق Android مكتوب بـ Flutter لملاك بيوت العطلات في الغردقة. يحافظ على تصميم MulkCare الأصلي، ويعمل بواجهة عربية RTL وإنجليزية LTR. ملفات JavaScript الأصلية باقية في `src/` مرجعًا للسلوك. بيانات النسخة الحالية تجريبية فقط.

## الشاشات

الدخول والتسجيل، الرئيسية، تفاصيل العقار، تقرير الفحص، الخدمات وتتبع الطلبات، الدليل المحلي، المساعد التجريبي، الاشتراكات، الملف الشخصي، الإشعارات، وشاشة المسار غير الموجود. لكل شاشة ملف Dart مستقل في `lib/screens/`.

## بناء APK عبر GitHub Actions

البناء يتم في GitHub Actions فقط على فرع `feature/flutter-migration-complete` باستخدام Flutter `3.47.7`. يولد runner ملفات Android اللازمة، ثم يشغّل التحليل والاختبارات وبناء APK. تُرفع نسخة APK كـartifact، ويرفع معها `pubspec.lock` كأثر منفصل لتثبيت الاعتماديات وتشغيل بناء نهائي ثابت.

افتح GitHub ثم **Actions → Build MulkCare APK**، واختر التشغيل الناجح، ونزّل artifact باسم `MulkCare-APK-…`. لا ينشئ الـworkflow إصدار GitHub عامًا ولا ينشر التطبيق على Play. معرف التطبيق `com.mullky`، والتوقيع الافتراضي debug غير مناسب للنشر التجاري. نتيجة Actions لا تعني أن APK جُرّب على هاتف فعلي.

## الحساب التجريبي والحدود

استخدم `owner@mulkcare.demo` وكلمة مرور من 6 أحرف على الأقل؛ كلمة المرور لا تُحفظ. الحالة محلية فقط. لا يوجد backend أو رفع صور سحابي أو AI حي أو خرائط/دليل مباشر أو دفع إلكتروني أو إشعارات push أو PDF. صور الخدمة تبقى على الجهاز وطلب الاشتراك لا يبدأ دفعًا. الأسعار المقترحة عينات للاختبار وليست أسعار سوق موثقة.

التصميم المرجعي `DESIGN.md`، وخط Tajawal والصور الثماني والقواميس الأصلية داخل `assets/`. ملفات `.agent/` توثق خطة النقل وحالته وأدلة التحقق.
