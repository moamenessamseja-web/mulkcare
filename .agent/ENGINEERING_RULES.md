# قواعد التنفيذ

تُراجع كل شاشة أصلية مقابل ملف JavaScript المقابل، ويظل `DESIGN.md` وقاموسا `ar/en` المرجع. لكل شاشة ملف Dart منفصل، وتُستخدم النماذج والحالة والترجمة المشتركة بدل تكرارها.

لا تُرسل بيانات أو كلمات مرور إلى شبكة. لا تتصل بخدمة خارجية أو مزود AI، ولا تعرض زرًا يوحي بأن إجراء الدفع أو رفع الصور أو PDF اكتمل. كل فعل تجريبي يغيّر الحالة المحلية فقط ويُعرض بوصفه محليًا/تجريبيًا. انتقالات الطلبات تمر عبر قائمة الحالات المسموحة؛ اسأل أو استخدم تأكيدًا للإجراءات غير القابلة للتراجع.

لا تُضعف الاختبارات أو تخفي أخطاء analyzer لإرضاء CI. يمكن تمرير style-only infos فقط بسبب `--no-fatal-infos`؛ التحذير والخطأ يظل فشلًا. لا تدّع نجاحًا قبل نتيجة Actions، ولا تدّع اختبار جهاز. لا ترفع تغييرات ملفات المنصة المولدة أو أسرار أو artifacts إلى Git.
