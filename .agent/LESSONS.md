# الدروس

- التحويل السابق على `feature/flutter-migration` لا يغطي كل الشاشات المطلوبة؛ عدد ملفات Flutter القليل لا يعني نقلًا كاملًا. لهذا أُنشئ الفرع الجديد من `main` ويُربط جرد كل شاشة بمصدرها الأصلي.
- لا تخلط بين «APK تم تجميعه» و«التطبيق اختُبر على جهاز»؛ يظل الاختبار اليدوي حالة مستقلة.
- Android scaffold يمكن توليده داخل Actions دون وضع SDK محليًا أو تتبع ملفات المنصة في الفرع.
- لا ترفع GitHub Release تلقائيًا إذا كان artifact خاصًا للتنزيل كافيًا؛ تجنب النشر الأوسع دون طلب.
- تذكير أمني: أي رمز وصول يُلصق في محادثة يجب ألا يدخل الملفات أو أوامر السجل؛ استخدم الاعتماد المهيأ للـCLI، ونبّه صاحبه لإلغاء الرمز المكشوف.
