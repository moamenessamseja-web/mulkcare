# سجل التغييرات

## 2026-11-02 — تصحيح تدفق الدخول وشريط التنقل

أبلغ المالك أن APK-5 لا يعرض إلا تسجيل الدخول ثم شاشة بيضاء، وأن أزرار الوجهات تظهر في الوسط ولا تعمل. مراجعة الكود وجدت أن الشريط السفلي كان داخل `Center` بلا ارتفاع محدد، وأن تسجيل الدخول/التسجيل لا ينفذ انتقالًا من المسار الجذري بعد تحديث الحالة.

أضيف ارتفاع ثابت لشريط التنقل، وانتقال صريح إلى `/` بعد نجاح الدخول أو التسجيل، واختبارا widget يمران بتدفق الواجهة الحقيقي ويضغطان وجهة خدمات. اجتاز التغيير فحص Dart الساكن `dart_sanity.py` و`git diff --check`. **لم يُترجم أو يُختبر بعد عبر Actions؛ لا توجد نتيجة خضراء لهذا الإصلاح حتى الآن.**
